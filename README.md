# sigil-polis-os

Sigil で作る汎用OS。製品名は **Machi**（正式表記は Sigil Machi）。polis＝古代ギリシャの都市。「アプリたちが暮らす街」という汎用OS の姿を名前の由来とし、os でオペレーティングシステムであることを示す。

## 位置づけ

- Sigil 一族の土台の1つ。一般用途に広く使える汎用OS を目指す
- 広い機器対応、アプリケーションの互換性、GUI など、sigil-os が ADR 0054 で明示的に対象外とした要求を、こちらが担う

## sigil-os との関係

- 別リポジトリにした理由: sigil-os は「信頼基盤の小ささ」が核であり（ADR 0054）、要求が正反対の汎用OS を混ぜると、その保証が崩れるため。別リポジトリにすべきかは typesafe-ai 正式判定で判断した（「別リポジトリ」が確率 1.0・confidence 1.0）
- 土台の再利用: 起動契約（UEFI ローダーと boot-info）と最小カーネルは sigil-os の成果を再利用し、その上に汎用OS としての層（広い機器対応・互換性・GUI）を積む

## 状態

リポジトリ作成済み（2026-11-25 に名前 sigil-polis-os と製品名 Machi を決定）。詳細な設計は今後 ADR で定める。実装はこれから。
